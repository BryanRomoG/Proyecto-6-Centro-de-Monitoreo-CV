# Alertas exportadas

Consultar `../escenarios/<normal|baja-confianza>/<run_id>/alerts.jsonl` y el
[índice](../indice.md). Las alertas refieren a los IDs de `events.jsonl`, su regla,
configuración, severidad, motivo y acción sugerida. La regla sostenida puede referir
además a `windows.jsonl`. No se guardan copias con IDs nuevos para aparentar más alertas.
