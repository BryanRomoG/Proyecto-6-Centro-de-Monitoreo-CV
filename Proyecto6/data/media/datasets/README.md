# Dataset de la versión pública propuesta

> Copia pública derivada. El README y los manifiestos originales de 80 imágenes se conservan localmente y en el commit previo.

Esta versión selecciona 79 imágenes distintas, con [manifiesto JSON](manifest.json) y
[CSV](manifest.csv). Se conserva autor, perfil, título, fuente, licencia, fecha y SHA por fotografía.
La imagen 26557008b4fcf408 queda fuera de esta selección porque su atribución contiene
un contacto; no se inventa un nombre alternativo ni se declara que su licencia sea inválida.

Las fotos pueden recuperarse con el [adquiridor](../../../scripts/download_demo_dataset.py)
usando la [selección pública](../../../config/dataset-selection-public.json). Las 79
ya presentes en Git conservan sus bytes; las descargas ausentes validan sus SHA.
No ejecutar la adquisición pública sobre el archivo histórico local de 80 entradas.
