# Fotografías públicas seleccionadas

80 JPEG distintos de Open Images validation, obtenidos por ID desde CVDF. Conservar
[manifest.json](manifest.json) y [manifest.csv](manifest.csv) junto a las fotos:
contienen autor, título, procedencia y licencia individual CC BY 2.0 de cada archivo.
El espejo oficial redimensiona a máximo 1024 píxeles; este proyecto conserva sus bytes.
Anotaciones/miniaturas/PNG son derivados identificados, no sustitutos del original.
Consulta [adquisición y licencias](../../../Docs/DATASETS.md) y
[CC BY 2.0](https://creativecommons.org/licenses/by/2.0/). No se atribuye autoría al estudiante.
