# Artefacto YOLOX-Nano

Obtener desde Proyecto6 con `python scripts/download_model.py --destino modelo`.
El [descriptor](descriptor.yaml) identifica URL pública, release, tamaño, SHA-256,
clases y contrato ONNX. El `.onnx` se excluye de Git y se verifica antes de cargar.
El artefacto se descargó de nuevo desde la fuente; no depende de la carpeta del Proyecto 5.
